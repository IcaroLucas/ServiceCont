# ServiceCont

# 📋 Gerenciador de Listas

> Aplicação web para criação, organização e gerenciamento dinâmico de listas de itens.

---

## 🚀 Tecnologias Utilizadas

- ReactJS / Css
- Java / SpringBoot

## ✨ Funcionalidades

- ➕ Criar e personalizar novas listas
- ✏️ Adicionar, editar e remover itens
- 🔍 Filtrar e buscar itens rapidamente
- ✅ Marcar tarefas/itens como concluídos
